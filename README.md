# clipboard+

clipboard+（クリップボードプラス）は、iPadでコピーした文章・URLを保存し、タッチ操作で使い直せるクリップボード管理アプリ。

ウインドウ表示やStage Managerの小窓で使うことを想定し、現在のウインドウサイズに合わせた画面を設計する。

## 開発状況

試作1は、ウインドウ表示AppでSafariからの20件収集試験に合格した。段階2（0.2.0）では、SQLiteへの保存、検索、ピン留め、重複の統合、削除の取り消し、ドラッグでの取り込み、JSON書き出しを実装している。仕様は[段階2の実装方針](docs/段階2の実装方針.md)。

ソースは `app/ClipboardPlus/`、単体テストは `app/ClipboardPlusTests/` にある。GitHub ActionsのmacOS 26（Xcode 26.6）上で `app/project.yml` からXcodeGenでプロジェクトを生成し、署名なしビルドとiPadシミュレータでのテストを行う。Windowsではコンパイルできない。段階2のビルド・XCTest・実機試験は未確認。

## 段階2の使い方

- 「記録を開始」で定期確認する。間隔は設定から0.1〜5.0秒（初期値0.5秒）に変更でき、間隔と記録状態は再起動後も残る。起動時の再開では既存のクリップボードを読み取らず、その後の変更から収集する。
- 「ペースト」または一覧への文章のドロップで手動保存する。行のタップでコピー、ドラッグで他のアプリへ持ち出せる。長押しとスワイプからピン留め・解除・削除ができる。
- 検索は原文の部分一致で、大文字と小文字を区別しない。「すべて／ピン留め」で表示を切り替える。
- 原文が完全に同じものは統合し、最後の収集時刻・回数・取り込み経路を更新する。空白や改行の違いは別項目。自己コピーの直後の読み取りでは更新しない。
- ピン留め以外は1,000件まで。上限を超えると最後の収集時刻が古いものから削除する。全消去ではピン留めを含めるか選択できる。削除後5秒間は直近の操作を取り消せる。期限切れのデータは削除し、アプリ停止中に期限が来た場合は次の起動・復帰時に削除する。
- 設定からすべての履歴をJSONで共有できる。原文が含まれるため共有先を確認する。取り消し待ちの項目は含めない。形式は `formatVersion: 1`、`exportedAt`、`entries`。各項目にはID、原文、種類、初回保存時刻、最終収集時刻、回数、ピン留め、最後の取り込み経路を含み、時刻はUTCのISO 8601形式（ミリ秒付き）とする。
- 設定の「計測ログ」からログの確認・書き出しができる。原文の記録は起動時にはオフ。

履歴DBはApplication Supportに置き、`PRAGMA user_version = 1` で版を管理する。URL表示は空白・改行を含まないHTTP/HTTPSの絶対URLを対象とし、原文を変更せずドメインを併記する。それ以外も文章として保存できる。画像・共有拡張・キーボード・iCloud同期・アプリ内復元・PiPは段階2に含めない。

全画面で他のアプリを使用中など、OSがclipboard+を停止している間は収集できない。定期確認の間に複数回コピーした場合も途中の内容は取り戻せない。段階2では20件収集、再起動、360pt程度の小窓、スクロール位置、Safariからのドロップ、JSON共有を実機で確認する必要がある。

## 開発方針

- 文章・URL・画像の履歴保存
- 小窓で使える一覧、検索、ピン留め
- 共有メニューとドラッグによる保存・再利用
- 記録の一時停止、削除の取り消し、容量管理
- 端末内保存とバックアップ

対応OSはiPadOS 17以降。Swift 5言語モードとiOS標準のSQLite3を使い、外部ライブラリは使用しない。

最初の試作の範囲、Macなしの開発経路、試験の手順は[試作1の実装方針](docs/試作1の実装方針.md)に記載している。

## 開発ツール

Claude Codeを司令塔とし、Codex CLIへ実装・レビューを依頼する。[CLAUDE.md](CLAUDE.md)に役割と呼び出し方法を記載している。VS CodeのClaude Code拡張でこのフォルダを開いて利用する。

呼び出しにはNode.jsとログイン済みのCodex CLIが必要。プロジェクトルートで次を実行すると、読み取り専用でCodexにレビューを依頼できる。

```sh
node scripts/invoke-codex.mjs --mode review --task "README.mdを読んで開発状況を確認してください"
```

実装時は `--mode implement` を指定する。`--model` と `--effort` でモデルと推論の強さを指定できる。Codexが利用制限に達した場合は、解除時刻まで待って自動で再実行する。Windowsではnpmでインストールした `codex.cmd` を利用する。
