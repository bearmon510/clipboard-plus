# clipboard+

clipboard+（クリップボードプラス）は、iPadでコピーした文章・リンク・画像・ファイルを自動で保存し、タッチ操作で使い直せるクリップボード履歴アプリ。

小窓（ウインドウ表示、Stage Manager、Slide Over）で横に置いて使うことを想定している。

## 現在の状態

バージョン0.14.0。TestFlightの内部テストで、iPad Air 13インチ（iPadOS 27.2.1）を使って確かめている。App Storeには未公開。

できること：

- **自動収集。** アプリを開くと記録が始まる。0.5秒ごと（設定で0.1〜5.0秒）にクリップボードの変更番号を確かめ、変わったときだけ内容を読む。同じ内容は1項目にまとめる。
- **使い直し。** カードをタップするとコピー、ドラッグするとほかのアプリへ持ち出せる。長押しか「⋯」で、全文の表示、リンクを開く、テンプレートへの移動、削除ができる。
- **履歴とテンプレート。** 上の「履歴｜テンプレート」で切り替える。よく使う文はテンプレートに移すと、タグごとにまとまり、自動削除と全消去の対象から外れる。
- **探す。** 検索（一致した部分を強調）と、日付ごとの区切り。
- **取り込み口。** 自動収集のほか、ペーストのボタン、ほかのアプリからのドラッグ、ショートカットとSiri。
- **画面の切り取り。** スクリーンショットから、文字か画像を選んで範囲を切り取り、クリップボードへ入れる。AssistiveTouchとショートカットから呼べる。
- **安全のための仕組み。** 一時停止、削除後5秒間の取り消し、30日（設定で変更可）を過ぎた履歴の自動削除、秘密の印が付いた内容の除外。
- **バックアップ。** 画像を含めて1つのファイルに保存し、今の履歴へ足し込む形で復元できる。
- **Windowsとの同期（試作）。** WindowsのPCとBluetooth LEで文章とリンクを両方向に送る。QRコードで一度組めば、場所やWi-Fiが変わっても設定し直さなくてよい。PC側のアプリは `windows/`。

まだないもの：同期での画像と、離れている間の分の追いつき、PCでの履歴の表示、共有メニューからの保存（共有拡張）、画像の中の文字の検索。

iPadOSの制約により、全画面のアプリでコピーした内容は、clipboard+へ戻ったときの最後の1件しか取り込めない。確認の間隔より速く続けてコピーした場合も、途中の内容は取り込めない。

## 作り

- iPad：SwiftUIとUIKit。対応OSはiPadOS 17以降、Swift 5言語モード、外部ライブラリなし。ソースは `app/ClipboardPlus/`、単体テストは `app/ClipboardPlusTests/`。
- 履歴はアプリ内のSQLite（iOS標準のSQLite3）に、画像とファイルはファイルとして保存する。端末の外へ送るのは、組んだPCとの同期だけ（暗号化する）。
- PC：.NET 10とWPF。ソースは `windows/`。iPadと共通の通信の決まりの例は `protocol/`。

## ビルドと配布

開発用のPCはWindowsで、Macはない。Swiftのコンパイルはできないため、GitHub Actionsで行う。

- `app/project.yml` からXcodeGenでプロジェクトを生成する。生成物はコミットしない。
- `ios-build.yml`：`app/` を変更したpushのたびに、署名なしのビルドとiPadシミュレータでのテストを行う。テストの中で主な画面を架空のデータで描き、画像を成果物 `screen-snapshots` として保存する。
- `ios-testflight.yml`：手動で実行する。署名してTestFlightへ送り、処理の完了を待って内部テストのグループへ追加する。署名情報はGitHubのSecretsに置く。
- `testpage.yml`：実機試験で使う、番号付きの架空の文章と画像のページを公開する。
- PC側は `dotnet test windows/ClipboardPlus.slnx` で確かめる。
