# clipboard+ 日常利用の仕上げ（0.5.0）

2026年11月15日。PiPを出していれば全画面でも裏で収集できることが分かり（[PiPの技術検証](PiPの技術検証.md)）、アプリの中心である「コピーした内容が保存される」はほぼ満たせた。利用者は今後の優先順位を一任した。機能を増やすより、毎日使いやすくすることを先にする。

利用者の判断（2026年11月15日）：
- バックアップ機能は残す。普段は使わないので目立たない位置でよい。
- 共有拡張は、PiPで全画面でも収集できるため優先度を下げる。日常的に使って必要になったら作る。

## 1. PiPを正式な機能にする

- **「試験中」の表示を外す。** 設定の名前は「PiPで裏でも収集」とし、説明は残す（小窓は状態の表示だけで触って操作はできない、再生・一時停止で記録の開始・停止、電池を使う）。
- **始めやすくする。** 本体の画面の上部に「PiP」ボタンを1つ置き、押すと記録の開始とPiPの開始をまとめて行う。PiPに対応していない端末では出さない。いまの小さな映像の表示（高さ60pt）は、PiPの元として必要な最小の大きさにし、場所を取らないようにする。
- **小窓からアプリへ戻る。** PiPの小窓の「元に戻す」ボタンで、clipboard+の画面が前面に出るようにする（`restoreUserInterfaceForPictureInPictureStop` に対応する）。
- **離れたら自動で出す（設定、初期値オン）。** 「PiPで裏でも収集」がオンで記録中のときに、clipboard+を離れると自動でPiPを出す（`canStartPictureInPictureAutomaticallyFromInline`）。小窓から戻ってclipboard+を使い、また別のアプリへ移ると、毎回ボタンを押さなくても小窓が出る。App Storeの審査では問題にされる恐れがあるので、公開前に見直す（[PiPの技術検証](PiPの技術検証.md)の「App Storeの審査について」）。

## 2. 設定の整理

上から次の順に並べる。

1. 収集（定期確認の間隔、PiPで裏でも収集、離れたら自動でPiPを出す）
2. 履歴の保存（自動削除、上限と使用量の説明）
3. 自動収集について（説明）
4. 書き出し（JSON）とバックアップ
5. 開発者向け（計測ログ、原文の冒頭をログに含める設定、scene状態）。普段は閉じておく（`DisclosureGroup` など）。

## 3. 合格条件

1. 本体の「PiP」ボタン1回で、記録とPiPが始まる。
2. 小窓の「元に戻す」で、clipboard+が前面に出る。
3. 自動で出す設定がオンなら、clipboard+を離れたときにPiPが出る。オフなら出ない。
4. 設定が上の順に並び、計測ログは「開発者向け」を開いたときだけ見える。
5. 文章20件・画像5枚の試験が、PiPありの全画面で合格する（これまでと同じ）。

## 実装メモ

- 0.5.0で実装。既存の `pictureInPictureEnabled` キーと初期値オフを維持し、自動表示は `pictureInPictureAutomaticallyStarts` に保存する（未保存ならオン）。PiP設定・記録中・自動表示設定がすべて真のときだけ自動開始を許可する。Combineの `@Published` は代入前に通知するため、記録状態の更新には通知された値を使う。
- 上部の「PiP」はアイコン付き、タップ領域44pt以上。設定オフ・記録停止中でも1回で有効化・記録開始・PiP開始要求を行う。初回はUIViewのウインドウへの接続・レイアウトとAVKitの開始可能状態を待ち、準備できなければ10秒で案内して再試行可能にする。準備待ち中の記録停止・設定オフでは要求を取り消す。PiP中は終了ボタンになり、記録は停止しない。
- 元映像はヘッダーの記録状態の横に16×9ptで1つだけ表示し、640×360の描画バッファは維持する。ゼロサイズ、画面外への移動、`hidden`、透明化は使わず、`AVSampleBufferDisplayLayer` をUIViewに載せたままにする。アクセシビリティ上だけ重複する映像を除外する。参照した公式資料では開始できるサイズの下限や完全非表示での保証を確認できず、16×9ptは実機で最小サイズと確認済みの値ではない。このサイズでの手動・自動開始、終了後の再開始を実機確認する必要がある。
- 復帰デリゲートで「PiPから本体へ戻る」を記録し、`completionHandler(true)` を呼ぶ。単一ウインドウの本体を保持しているため、画面を新規作成せずシステムの復帰処理を完了させる。設定は「収集→履歴の保存→自動収集について→JSON書き出し→バックアップ→開発者向け」の順。開発者向けは初期状態で閉じ、長い設定名は折り返す。
- XCTestを9件追加（自動開始の全8組み合わせ、ボタンからの有効化と記録開始、自動表示オフでの手動開始、初期値、両値の保存と再読み込み、旧キー互換、記録・設定変更への即時追従、開始待ちの取り消し、復帰完了とログ）。ボタンテストはシステムPiPの開始要求だけ差し替える。AVKitの状態更新・待機テストは非対応シミュレータではスキップし、純粋な判定と設定・ボタンのテストは実行する。
- Windowsで差分・参照先・設定順・公開ファイルへの個人情報混入を静的確認。Swiftコンパイル、XCTest、XcodeGen、360ptでの実際の描画は未実施。GitHub ActionsのmacOS（Xcode 26.6、Swift 5、iPadシミュレータ）で既存テストを含むビルドとテストが必要。コミット・push・Actions起動は行っていない。
- 実機確認：設定オフ・記録停止からの1回開始、小窓から本体への復帰と再離脱、自動表示オン／オフと記録停止時の挙動、小窓の再生・一時停止、設定オフでの終了、全画面の別アプリで文章20件・画像5枚の収集（小窓を端に隠した場合も）、360ptでの上部ボタン・設定・開発者欄の折り返し。既存の履歴操作・保存・復元も回帰確認する。電池・発熱とApp Store公開前の用途確認は引き続き未確認。
